# DnDice Companion

App per acompanyar partides de Dungeons & Dragons. La app compta amb fitxa del personatge, tirades de daus, llibre de màgies i armes.

## Pantalles

- **Inici:** el logotip apareix amb una animació i després es mostra una pantalla d'ajuda amb el botó «Començar».
- **Personatges, Daus, Màgies i Armes:** les quatre seccions principals, amb opcions de creació i modificació d'elements.
- **Login, registre i preferències:** s'obren des de la barra superior.

## Menús

- **Barra inferior:** quatre botons amb icones per canviar de secció. El botó de la secció activa es veu d'un altre color.
- **Barra superior:** dues icones, una per iniciar sessió i una altra per a les preferències.

## Llistes

Personatges, màgies i armes són llistes que es poden editar:

- **Afegir:** botó **+**.
- **Modificar:** mantenir premut un element.
- **Eliminar:** icona de la paperera.

Cada acció mostra un missatge a la pantalla.

Cada llista té un **Adapter**, que omple la llista amb les dades, i un **Holder**, que guarda les vistes de cada fila perquè es puguin reutilitzar.

## Accessibilitat

- Mode fosc i mode d'alt contrast a les preferències.
- Botó per obrir la configuració de TalkBack.
- Totes les icones tenen una descripció per als lectors de pantalla.
